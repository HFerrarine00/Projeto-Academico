# LearnHub – Plataforma de Tira-Dúvidas Acadêmicas

Projeto desenvolvido como parte da disciplina "Experiência Criativa – Projetando Soluções Computacionais" no curso de Engenharia de Software da PUCPR.

O LearnHub é uma plataforma web interna voltada ao ambiente acadêmico, com o objetivo de integrar a comunicação entre alunos, monitores e professores. A aplicação permite o envio, resposta e avaliação de dúvidas relacionadas a disciplinas, promovendo a colaboração por meio de gamificação e centralização de perguntas e respostas.

Principais funcionalidades:
- Cadastro de alunos, professores e monitores
- Registro e resposta de perguntas por disciplina
- Avaliação de respostas por alunos
- Visualização de rankings de monitores
- Histórico de dúvidas e interações

O sistema foi projetado com base em user stories, diagramas e modelo relacional, visando uma experiência fluida e organizada para todos os usuários envolvidos.
